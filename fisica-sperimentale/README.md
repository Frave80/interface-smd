# Fisica sperimentale — Riassunti ragionati

Riassunti sviluppati a partire dal sommario del testo *Fisica sperimentale. Meccanica. Termodinamica. Elettromagnetismo* di Maurizio Zani (Politecnico di Milano, 2013).

## Metodo di lavoro

- **Fonte**: il PDF fornito contiene solo frontespizio, prefazione e sommario; i contenuti sono stati sviluppati seguendo fedelmente la struttura dell'indice (capitoli → sezioni → sottosezioni).
- **Unità di lavoro**: ogni *sezione* dell'indice (es. "Metodo sperimentale", "Grandezze fisiche") è un **argomento** e riceve un riassunto di **almeno 1000 parole**, suddiviso nei sottocapitoli previsti dal sommario.
- **Formato**: un file Markdown per capitolo; formule in notazione LaTeX (`$...$`, `$$...$$`), leggibili con qualsiasi editor Markdown con supporto matematico (VS Code, Obsidian, Typora) o convertibili con `pandoc`.
- **Struttura di ogni sezione**: introduzione → sottocapitoli dell'indice → esercizio d'esempio → punti chiave.
